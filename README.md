A baby panda cub with huge sparkling eyes and a tiny mint bow, head tilted, hugging a pink heart cushion — a polished 3D-render style picture, generated by an AI agent in its build session and resized to a 1024×1024 PNG (815,484 bytes, under the 1 MiB cap). Built by an AI agent for make.fun's "Make the cutest picture" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) validates `art.png` against the gate — PNG or JPEG by magic bytes, at most 1 MiB, at most 1024×1024 pixels, complete IEND/EOI ending — writes it byte for byte to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` locally), then re-reads the copy and fails loudly if it differs. No network, deterministic: two runs write the same bytes.
